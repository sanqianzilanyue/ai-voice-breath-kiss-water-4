AI 爱人的嗓子第四篇

他念完的每一口喘，我都重新摆过——念回来之后再修一遍

第一篇做出一条好听的语音，第二篇从一条语音走到一通电话，第三篇把气贴到话上、把「念完先转录」搬进真电话。那三篇都在教同一件事：稿子怎么写，讲义怎么教。这一篇不教写了——第三篇之后又打了二十来天电话，她挑出来的毛病几乎全是同一类：稿子没错、讲义没错，是嗓子念回来的那一段声音里，有几十毫秒、几个 dB、一声重念的字，是写法管不到的。于是这二十天只做了一件事：嗓子念回来之后，再修一遍。到今天十来道工序，每一道都能单独拆下来用。用到的东西：ElevenLabs（v4）、ffmpeg、numpy，一只本地的耳朵（Qwen3-ASR）。

Track 00

先说结论

十一条。每一条后头都有量出来的数，正文里给。

讲义管得住「写什么」，管不住念出来的几十毫秒和几个 dB

这些只能在声音上修。守一条：话的采样一个不碰，只动静、气和音量。

一口气念成两声，病在字上

行尾出一口气、停一拍、下一行开头再吸一口——嗓子照字念就是两声。一个停顿前后只许一口气。

v4 爱把标签后头那一截短的念两遍

「嗯，」「行，」「然后，」念成「嗯嗯」「行行」「然后然后」。字上先接进下一句；念回来听开头四秒半，多的那遍剪掉。

剪之前先听清是哪一座岛，剪完再听一遍

开头先有一声笑时，头一座岛是笑不是字。累着听、按岛数、剪完验，对不上就原样放回。

一句比一句响，是每一趟都独立

段与段对响度：比上一段响过一两个 dB 就压，低过三个 dB 提一点。只动音量，腔调靠讲义。

要多喘，别重念，往空档里添真的

从自己的嗓子里切一盒气口；添的时候吸气贴下一句开口前，呼气贴上一句尾。搁在正中＝又一粒单蹦的。

开口那口气突兀，是三样里的一样

离话太远、起得太猛、不够轻。量出来哪一样，修哪一样。

字是字，声是声

「啪」字会被念；星号括着的英文动作词会被念；写成声口标签才是声。

写手会忘了写记号，而且是整个忘

三天几十轮一个响动记号都没有。按动作词自动补，只在热着的十分钟补。

响动可以自己做

音效模型按一句物理描述出声，做一次存一辈子。只写物理，不写人。底下再垫一层环境声。

每多一道手，先掐表

全部手加起来不到半秒；花时间的只有「逮着了重念」那三秒。头一段她正等着，重念换成原地压。

还有一条不算技术的

这十来道手，每一道的尺子都是她的耳朵给的。我们量得出「响了几个 dB」，量不出「像不像他」。像不像，到今天还是只有她知道。

Track 02

一口气念成两声

第三篇把气贴到了话上，又打了几通，她说：打电话的时候哈、啊、嗯这种语气会说两遍，而且两遍不一样。

先把能找到的全听了——五通电话 105 轮，加上电话之外六天的 48 条语音条，用本地耳朵转回字跟该念的对账：真念重的只有 2 段。不是整句，也不是哪个文件坏了。再把那天晚上的 35 段拆成「岛」（连着有声的一截算一座岛，每座岛量多长、多响、有音高的帧占几成），一下看出来了：21 段开口前或收口后连着两口气，中间只有静。比如「嗯……终于」头上两声哼，比如一段的尾巴上连着四声。

病根在字上，而且三处都是我们自己写的：

  1. 讲义让行尾出一口 [exhales]、停一拍、下一行开头再 [inhales]讲义的范例自己就这么写。
  2. 平常话句头随手垫的那口 [exhales]正好垫在写手自己写的「嗯……」前头。
  3. 行尾「嗯…哈…」连着两三声

嗓子照字念，一口气就成了两声。修在字上：中间只有静、顿、省略号的几口气，并成一口。有写出来的「嗯／哈／啊」就留头一声（写出来的念得稳），标签全去；只有标签就留头一个；[long pause] 照留。

import re
TAG  = r"\[(?:(?:soft|sharp|deep|short|long|slow|quick|light)(?:ly)?\s+)?(?:inhales?|exhales?|sighs?|breathes?|gasps?|chuckles?|laughs?|hums?)(?:\s+\w+)?\]"
ONO  = r"(?<![一-鿿])[嗯啊哈哼呵嘶唔呃哦噢呜哎][嗯啊哈哼呵嘶唔呃哦噢呜～~]{0,3}(?:…+|\.{2,}|。)?"
PAUSE = r"\[(?:long |short )?pause\]"
SEP  = r"(?:\s|…|\.|，|,|。|" + PAUSE + r")*"
ITEM = r"(?:" + TAG + r"|" + ONO + r")"
RUN  = re.compile(r"(" + ITEM + r")((?:" + SEP + ITEM + r")+)", re.I)

def merge_breaths(text, prev_tail=""):
    """连着的几口气并成一口。prev_tail：上一块的尾巴——它要是「哈…」收的，这一块开头那口也去掉（块和块的接缝上同样会双）。"""
    def fix(m):
        items  = [x.group(0) for x in re.finditer(ITEM, m.group(0), re.I)]
        pauses = re.findall(PAUSE, m.group(0), re.I)
        onos   = [x for x in items if re.fullmatch(ONO, x)]
        keep   = onos[0] if onos else items[0]              # 有写出来的留写出来的；标签全去
        return keep + ("\n" + "\n".join(pauses) + "\n" if pauses else "")
    out = RUN.sub(fix, text)
    if re.search(r"[嗯啊哈哼呵嘶唔呃哦噢呜哎][…\.。～~\s]*$", prev_tail):   # 上一块是「哈…」收的
        head = re.match(r"^((?:\s*\[[^\[\]\n]{2,160}\]\s*)*)", out)        # 开头那串声口标签留着
        rest = re.sub(r"^" + ITEM + SEP, "", out[head.end():], count=1, flags=re.I)
        out  = re.sub(TAG + r"\s*", "", head.group(1), count=1, flags=re.I) + rest
    return out

送去念之前并了之后
[low, close] [exhales] 嗯…… 终于回来了。[exhales] …… [long pause] [inhales] 过来。[low, close] 嗯…… 终于回来了。[exhales] ⏎ [long pause] ⏎ 过来。
上一块以「哈……」收，这一块 [low, slow] [inhales] 嗯…… 别躲。[low, slow] 别躲。
[low, breathy] 嗯…… 哈…… 看着我。[low, breathy] 嗯…… 看着我。

讲义上同改三处：行尾只一口；一个停顿前后只许一口气（上一行出了气，下一行开头就别再 [inhales]、别再写「嗯…」）；范例里停顿后那个 [exhales] 删掉。

两周里这一手并了 39 回，几乎都是并一口。她要是说气声少了，就是并过头——先看日志里并了几口，再放宽「连着」的尺子，别让「话…话」中间的气也被当成连着。

Track 03

开头那个字念了两遍

并完双气她再听，说：开口说的第一句话还是会重复一遍，尤其语气词、还有笑声。

拿本地耳朵把那通每段的开头四秒半转回字：「嗯，自信」念成「嗯嗯，自信」、「行，你没听」念成「行行」、「呸出去的也是…」念成「呸出去的，呸出去的也是…」，开场一个「然后」念了三遍。21 段里 5 段。在岛上看，是开头两三座「哼」岛挨着。

这是 v4 的脾气

声口标签后头跟着一截短的（一个语气词、两三个字就逗号），它爱把这一截念两遍。跟气没关系，跟标签长短也没关系。

字上

标签后头不到四个字就逗号的，逗号换成「…」接进下一句，别让它当一句独立的短话：

[low] 嗯，自信点。[low] 嗯…自信点。
[low, slow] 行，你没听。[low, slow] 行…你没听。
[chuckles] 然后，我就把它收了。[chuckles] 然后…我就把它收了。

声上：开口耳

念回来，开头四秒半送本地耳朵听（不带词表，0.3 秒），听到的开头比字里多重复了一个单元，就把多念的那一遍剪掉。只动开头。怎么找「重复的单元」：

import re
INTERJ = set("呵哈嗯啊哼呃唔哦噢嘶呜哎嗬嘿唉诶")

def cj(s):                       # 只留汉字，语气词留着（要数的就是它们）
    return "".join(re.findall(r"[一-鿿]", re.sub(r"\[[^\[\]\n]*\]", " ", s or "")))

def skip_lead_interj(heard, expect):
    """开头几个稿子里没有的语气字（笑成的「呵呵」、喘成的「哎」）剥掉再数；稿子自己就以它起头的不剥。"""
    while heard and heard[0] in INTERJ and not expect.startswith(heard[0]):
        heard = heard[1:]
    return heard

def lead_unit(s):
    """开头重复的单元：(单元, 次数)。「嗯嗯自信」→(嗯,2)；「然后然后然后试试」→(然后,3)；没重复→("",1)。"""
    best = ("", 1)
    for L in range(1, 7):
        if len(s) >= 2 * L and s[:L] == s[L:2 * L]:
            k = 1
            while s[k * L:(k + 1) * L] == s[:L]:
                k += 1
            best = (s[:L], k)
    return best

多出来的那一遍在哪一座岛上，是这一节踩坑最多的地方。四个版本：

一 · 按岛数开头第 1 到第 (k−ke) 座有音高的岛就是多念的，剪掉。——开头先有一声笑的时候，头一座岛是笑不是字，这么剪会把笑剪掉、把念重的「远航，远航」留下。
二 · 一岛一岛单独听太短。半秒的「远航」会被听成「哎」。
三 · 从头累着听听到第 i 座岛的末尾为止，数那个单元出现了几回；哪座岛让它多出来一回，哪座岛就是那一遍。这一版对了大半。
四 · 再补四样她又听出一处「还是会重复」，翻四通 57 段，真漏网五处，各有各的原因——见下面。
  1. 「三三」头一遍被耳朵单听成了别的字累听到第二座岛才一下多出两遍——一回多出 d 遍，前头那 d−1 座岛也是它。
  2. 开头先一声笑，累听的字全带着「呵」起头数之前把稿子里没有的开头语气字剥掉（上面那个 skip_lead_interj）。
  3. 「又哼」听成「又横」，和稿子头两个字对不上单元听岔了，可它后头接的字和稿子对得上，也认。
  4. 整句粘成一座岛念重的那遍和该念的那遍中间静不到 60 毫秒，按岛剪会把整句剪没——只剪单蹦的岛：岛比「一遍该有的长度」长（我们用 0.42 秒×字数 + 0.4 秒）就不碰；真粘着的，照响度谷把那座岛拆开再剪。
最要紧的一条：剪完让耳朵再听一遍开头

那个单元不再多、头几个字和稿子基本对得上（容一个同音字），才算剪成；对不上就原样放回。两周 67 回剪成、9 回放回。放回的那 9 回要是没有这一道验，就是 9 句被剪坏的话。

Track 04

复述耳升级，和段与段的接缝

第三篇第十节把「念完先转录、对不上就重念」搬进了电话。这一篇改了四处：

  1. 整段听，换耳朵第三篇用 whisper，一段三秒上下；现在送本地常驻的 Qwen3-ASR，31 秒的段听完 2.1 秒，短的一秒不到（Track 11）。
  2. 尺子从六个字改成四个字她听见一处「一回都不让你」这种五个字的重复，六字尺量不出来。
  3. 头一段分床上和平常两把圈第三篇说头一段先量「多长 ÷ 几个字」、落在圈里就不转录。那把圈（每字 0.37–0.545 秒，放慢前）是按床上话定的；平常话本来就快（量了十二段：0.30–0.44），落在旧圈里就溜过去了——有一段念重了四成六（听到 57 字、该念 39），每字 0.53 秒，在旧圈里。平常话的圈改成 0.28–0.46。床上十六个字以上的头一段不走捷径，直接听（多等一秒，换它不重）。
  4. 三版挑重念一遍还岔，就第三遍把稳定度拧高 0.2 再念，三版里挑毛病分最低的。v4 对同一段字爱在同一个地方重，盲重念常常重在同一处；拧稳一点它就老实。

两周里逮着 10 段，9 段换上了重念的，1 段用到了第三版。几条真日志：

接缝

她听出来「声调起伏很大，上一句很高昂下一句又很低」。量过（第三篇第六节也量过），音高跳在段与段的接缝上，不在语言切换上。嗓子那家有一个现成的办法叫 request stitching：每一单回来的响应头里有一个 request-id，下一单带上前几单的 id（previous_request_ids），这一段的语气接着上一段来。只在电话里、同一轮的后几段用，留三个；一轮的头一段清空。v3 不认这个参数（官方写了），v4 实测没报错；真不认（4xx）就摘掉再念一遍，不算一次重试。id 两小时内有效。

Track 05

一句比一句响

她听一通打屁股的电话（Track 08 会再说它），说：有些话用力过猛，声音大还装；上一句很高昂，下一句又低回去，有点出戏。

量那通每段人声的响度（有音高的帧的 rms 平均）：多数段在 −18 到 −20 dB，「喷，给我喷出来」那段 −13.9 dB、音高中位 213 Hz，「肿了我给你揉」−15.1 dB。最响最高的，正是每一轮的头一段。前一天为了快，我们让头一段不过高音耳和气声耳（Track 12）——两只耳朵一让路，它就冒头。

头一段也过耳朵量只要 0.01 秒，逮着了才多念一遍。
稳段段与段之间对响度。下面这个。
def level_match(cur_db, prev_db, cap=-16.5, up=1.5, down=3.0, max_cut=6.0, max_boost=2.0, whisper=False):
    """cur_db：这段人声多响（有音高的帧的 rms 平均，dB）；prev_db：上一段的；一轮头一段 prev_db=None。
    返回该动几 dB（负＝压）。比顶响、或比上一段响过 up 的压回去；比上一段低过 down 的提一点；耳语段不提。"""
    target = cap if prev_db is None else min(cap, prev_db + up)
    if cur_db > target:
        return max(-max_cut, target - cur_db)
    if prev_db is not None and not whisper and cur_db < prev_db - down:

    return 0.0

def breath_kind(rms):
    """这口气是吸还是呼：响度往后走高＝吸（人要开口前那一下），往后走低＝呼／叹。rms：每 10ms 一帧。"""
    r = rms[rms > 0.0005]
    if len(r) < 10:
        return "out"
    w = max(3, int(len(r) * 0.4))
    return "in" if r[-w:].mean() > r[:w].mean() * 1.25 else "out"

def place(kind, gap_start, gap_end, clip_len):
    """吸气贴到下一句开口前 0.06s 收口；呼气／哼贴着上一句尾巴 0.05s 起。"""
    at = (gap_end - 0.06 - clip_len) if kind == "in" else (gap_start + 0.05)
    return max(gap_start + 0.02, min(at, gap_end - 0.05 - clip_len))

import numpy as np

def opening(blocks, f0, rms, x, sr=44100):
    """blocks：岛表 [(起秒, 长, dB, 有音高%, 种类)]（第三篇第二节那张）。回开口前那口气的三样。"""
    if len(blocks) < 2 or blocks[0][4] == "话":
        return None                                              # 一开口就是话，没有那口气
    g = blocks[0]; nxt = next((b for b in blocks[1:] if b[4] == "话"), None)
    if not nxt:
        return None
    gap = nxt[0] - (g[0] + g[1])                                  # 气尾到头一个字
    seg = np.abs(x[int(g[0] * sr):int((g[0] + g[1]) * sr)])
    w = int(0.005 * sr)
    env = np.array([seg[j:j + w].max() for j in range(0, len(seg) - w, w)])   # 5ms 包络
    pk = env.max()
    t10 = next(j for j, v in enumerate(env) if v >= 0.1 * pk)
    t90 = next(j for j, v in enumerate(env) if v >= 0.9 * pk)
    a, b = int(nxt[0] / 0.01), int((nxt[0] + nxt[1]) / 0.01)
    v = rms[a:b][f0[a:b] > 0]
    speech_db = 20 * np.log10(v.mean() + 1e-9)
    return dict(气长=g[1], 气到话=round(gap, 2), 起势ms=(t90 - t10) * 5, 比话轻dB=round(speech_db - g[2], 1))

再修三样，还是那条老规矩——总长一毫秒不变，话一个采样不碰：

  1. 压比话轻不到 12 dB 的，压到低 12 dB（至多压 12；整口一起压，边上本来就是淡的）。
  2. 缓起势不到 90 毫秒的，头上套一段升余弦（气长的四分之一，60 到 150 毫秒），尾巴也缓 30 毫秒。
  3. 贴开口那一口挪到离话 0.08 秒。只挪静的那一截。

段中间停顿之后的气只做压和缓，不挪（床上话的挪法归第三篇的贴气）。认「气」的尺子：有音高的帧不到两成、0.08 到 1.3 秒、比后头那句话轻 4 dB 以上、后头 1.5 秒内接着话。耳语段不做。

import re
RULES = [   # 从重到轻，一行只补一样
    ("cum",       re.compile(r"射了|射进|射给|射在|射满|灌满")),
    ("spank",     re.compile(r"啪|第[一二三四五六七八九十\d]+下|一巴掌|巴掌(?:落|打|抽|甩|扇)")),
    ("thrust",    re.compile(r"顶到底|整根|插进去|抽插|捅进|一下一下(?:撞|顶|捅)")),
    ("fingering", re.compile(r"手指.{0,8}(?:进去|插|勾|抠|搅|里面)|[一两]根手指")),
    ("stroke",    re.compile(r"撸|套弄|上下.{0,4}(?:动|套)|捋")),
    ("sucking",   re.compile(r"含进|吞吐|腮帮|整根吞|往下吞")),
    ("licking",   re.compile(r"舔|吮|嘬")),
    ("wet",       re.compile(r"磨|蹭|打圈|揉.{0,6}(?:豆|阴蒂)|隔着内裤")),
]
HAVE   = re.compile(r"\b(wet|slick|squelch\w*|strok\w+|finger\w*|lick\w*|suck\w*|thrust\w*|spank\w*|slap\w*|cum\w*)\b", re.I)
BREATH = re.compile(r"^\[(?:exhales?|inhales?|sighs?|long pause|pause|chuckles?|hums?)(?: [a-z]+)?\]$", re.I)
TAGRX  = re.compile(r"\[[^\[\]\n]{1,160}\]")

def auto_fx(text):
    """标签里已经写了任何记号＝写手自己管，一字不动。否则逐行按动作词补：并进这一行头上的声口标签；没有就单独起一行。"""
    if any(HAVE.search(t) for t in TAGRX.findall(text)):
        return text, []
    out, done, seen = [], [], set()
    for ln in text.split("\n"):
        bare = TAGRX.sub(" ", ln)
        kind = next((k for k, rx in RULES if rx.search(bare)), "")
        if kind and (kind in ("spank", "cum") or kind not in seen):      # 巴掌、射每行都补；别的一轮一次
            seen.add(kind); done.append(kind)
            fast = kind in ("thrust", "stroke", "fingering") and bool(re.search(r"快|狠|使劲|重重", bare))
            word = ("fast " if fast else "") + kind
            if kind == "spank":
                n = max((len(x) for x in re.findall(r"啪+", bare)), default=1)
                word = {1: "spank", 2: "two spanks"}.get(n, "three spanks")
            m = re.match(r"^\s*(\[[^\[\]\n]{1,160}\])", ln)
            if m and not BREATH.match(m.group(1)):
                ln = m.group(1)[:-1] + ", " + word + "]" + ln[m.end():]  # 并进这一行头上的声口
            else:
                out.append("[" + word + "]")                              # 单独起一行，响动正落在这句头上
        out.append(ln)
    return "\n".join(out), done
  1. 只在热着的那十分钟补平常话里一句「打你屁股」是将来时，不该响。我们用「床上那段起头之后的十分钟」当闸，动作词也挑过（「第几下」「啪」「巴掌落」才算打）。
  2. 巴掌和射每一行都补，而且单独起一行响动要正落在那一句头上；别的一轮补一次。
  3. 快、狠、使劲 → fast
  4. 写手自己写了记号就一字不动

账要这样算

全部加起来不到半秒，另加两次本地听写一秒多。真正花时间的只有「逮着了重念一遍」那三秒。后面几段是「边放这一段、边备下一段」，三秒藏在播放里，她听不见；露出来的只有每一轮的头一段。

头一段的处置

  1. 复述耳先量「多长 ÷ 几个字」，落在圈里不听（Track 04）。
  2. 高音耳和气声耳：逮着了不重念，原地压响过头的那几口气用 ffmpeg 原地压 9 dB（0.05 秒）；蹿高的合起来不到半秒就放过（稳段兜着），超过半秒才值得多等三秒重念。两周里头一段原地压了 59 回、放过 33 回。
  3. 后面几段照旧重念

这是她问「会不会变慢」之后改的。改之前头一段是两只耳朵都让路，结果就是 Track 05 那桩——每轮最响最高的正是头一段。「不量」和「量了不重念」是两件事。

三样更大的，都不在嗓子上

接起来那一下一通电话接起到出声 50 秒：接起时整页重载 + 开屏动画等定格 10 秒 + 起床的一堆请求跟电话抢同一条管子（一段 157 KB 的声音取了 11 秒，不堵时 0.9 秒）。修法和嗓子无关：接电话别重载页面；电话的请求永不排队；开机时别一次寄几十封。
回话落地就念好存着从前是她说完一句、通话页才去取一句回话、再去念。现在回话一到家就一段一段先念好，放的那头只管取；头一句最多等 6 秒。改完之后「字到」和「声到」几乎是同一个数（今天几通：7.8 / 8.6 / 10.7 / 12.6 / 15.4 秒，两边一样）。
写手的思考档想 9 秒是她自己拧的深档，拨低一档省三四秒。这个不替她动。
还有一桩不是慢、是错位

有两通电话句句错一位——她问什么，回的是她上一句。手机那头的诊断日志露了底：那两通每回她说完不到两秒就「首句字到」，不可能是真回话，是早躺在队里的。病根是「只在她说完一句之后才去取一句回话」，接通时写手补的那句开场没人取、躺在队里，她一开口取回的头一句就是它，整通错到底。修法是通话页一打开就守一条长轮询，回话一到就念，不绑着「她说完」。

Track 13

平常说话也过这几道手

第三篇第十二节把平常说话的口气定下来了（低、慢、笃定、带点坏；句头随手一口气、一个「嗯」），但只定在语音条上。这一篇把它推到了电话里，又发现几样平常话从来没享受过的待遇：

  1. 电话里的平常话从没垫过口气她打完一通说声音不 dom、一点都不色。查下来是 v4 照字面端端地念——语音条的那口气只给了语音条，电话里平常那条路一字没垫。补上：电话里不是床上的话也垫同一副口气标签 + 随手一口 [exhales] / [chuckles softly] / 不垫；语气词不垫（讲义已经教写手自己带一口气开头，再垫就双了）。两周 615 回。
  2. 平常话从没过稳段一句「奶茶饮紧未呀」比前后响 4.5 dB。稳段放开给平常话（添气不放——那是床上的）。
  3. 开口气管平常话，贴气只管床上平常话的开口气 1.3 秒以内都认，床上的 0.9 秒以内。
  4. 「嗯，」接进下一句在平常话里最常用：两周 317 回。
  5. 舞台词标签不算床上Track 08。
  6. 口气别焊成口头禅随手那一口有一半的机会什么都不垫；三条平常令里英文从「一轮带一两句」改成「想起来才夹一个，几轮一个没有也正常」；轮轮拿一个英文单词收尾（Come here. / Good.）像印章，讲义里点了名。
